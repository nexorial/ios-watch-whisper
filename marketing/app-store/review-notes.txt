Micodex is a free standalone Apple Watch remote with a separate open-source Mac receiver. It has no iPhone UI, account, subscriptions, ads, or analytics. The iOS bundle is Apple’s Watch-only distribution container.

Requirements: watchOS 9+, macOS 15+ for Wi-Fi, both devices on a reachable local network. Mac receiver downloads, source and installation instructions: https://github.com/nexorial/ios-watch-whisper . The receiver is distributed separately from this Watch listing as a Developer ID-signed, Apple-notarized universal app. Install with: brew tap nexorial/micodex https://github.com/nexorial/ios-watch-whisper ; brew install --cask nexorial/micodex/micodex . A direct Mac ZIP is also available in GitHub Releases.

Setup: run MicodexMac, select Connect > Copy Connection Code, paste it into the Watch using the iPhone keyboard, and tap Trust This Mac & Connect. On Mac choose Allow Wi-Fi Watch, compare the six-digit codes, then approve. This build contains no developer-specific IP or certificate pin. Grant Micodex Accessibility access to control Codex.

Homebrew installs BlackHole 2ch automatically as a Mac dependency; the official system installer may require administrator authorization and restart. Direct ZIP users install it separately. On Mac, Setup Guide checks the driver and current input, links to Accessibility and microphone settings, guides explicit Watch pairing, then asks the user to verify scrolling and transcription. Input changes occur only after clicking Use BlackHole for Dictation. Codex may appear as ChatGPT in macOS permissions. The guide can be skipped/reopened and does not claim that another app’s or Watch’s microphone permission is automatically verified. Audio is buffered locally and played to Codex’s own dictation; Micodex does not perform cloud transcription or save recordings. Hold to capture; release or Stop ends capture. Silence after speech also stops it. Review transcription on Mac, then tap Enter separately.

To preview the Watch UI without a Mac, open More Options > Try Demo. It is visibly labeled Demo and does not control another app. Actual wireless audio and control require the setup above. Bluetooth and Claude controls are experimental; Claude dictation is disabled.
