# Project direction

Micodex is a Watch-first remote for an existing Mac AI workflow: Crown scrolling, Watch microphone dictation, and deliberate Enter. The Mac receiver owns the target adapter and local audio routing; the Watch remains a standalone app.

The public-source baseline keeps existing pairing identities, separates setup from the remote UI, provides portable full-certificate-pin setup, removes developer-specific release defaults, and documents reproducible builds.

Remaining work is tracked in [validation](VALIDATION.md) and [releasing](RELEASING.md). Internet relay, automatic sending, side-button remapping, and background Mac wake are outside the current scope.
